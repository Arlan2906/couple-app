# Арлан & Настя 💞

Telegram-бот с Mini App для двоих. Пять вкладок:

| Вкладка | Что делает |
|---|---|
| 🏠 Мы | Счётчик дней вместе и таймлайн моментов с фото |
| 🎁 Желания | Два вишлиста, тайная бронь подарка (владелец не видит, кто что взял) |
| 😊 Настрой | Смайлик и пара слов за день, история за 2 недели, уведомление партнёру |
| 💰 Копилка | Цели, кто сколько внёс, прогресс, уведомления на 25/50/75/100% |
| ✅ Мечты | Бакет-лист, отметка «сбылось» с фото |

Бот присылает партнёру уведомление о каждом новом действии.

## Как устроено

Один сервис — один процесс:

- **FastAPI** отдаёт API (`/api/...`) и сам Mini App (`static/`) — отдельный хостинг для фронта не нужен.
- **aiogram 3** работает в том же процессе через long polling — вебхук настраивать не нужно.
- **База**: SQLite локально, Postgres на сервере (переключается переменной `DATABASE_URL`).
- **Фото** хранятся в Telegram: бот отправляет фото самому автору, берёт `file_id` и сразу удаляет сообщение. В базе лежит только `file_id`.
- **Безопасность**: каждый запрос подписан Telegram (`initData`), сервер проверяет подпись токеном бота. Данные видны только двум людям из пары.

```
app/
  main.py    — запуск FastAPI + бота
  api.py     — все эндпоинты
  bot.py     — /start, приглашения, уведомления, фото
  auth.py    — проверка подписи Telegram
  db.py      — модели базы
  config.py  — настройки из .env
static/      — Mini App (HTML/CSS/JS, без сборки)
```

## 1. Создать бота (2 минуты)

1. В Telegram открой **@BotFather** → `/newbot` → придумай имя и username.
2. Скопируй токен. **Никому его не отправляй** — он даёт полный доступ к боту.

## 2. База данных на Neon (бесплатно, без срока)

1. **neon.tech** → Sign up with GitHub → создай проект (регион — Frankfurt).
2. На главной проекта нажми **Connect** → скопируй строку подключения вида
   `postgresql://...@ep-....neon.tech/neondb?sslmode=require`.

## 3. Запустить на Render

1. **render.com** → Sign up with GitHub.
2. **New → Web Service** → выбери репозиторий `couple-app`.
3. Настройки (большинство подставятся сами):
   - Runtime: **Python**, Region: **Frankfurt**, Instance type: **Free**
   - Build command: `pip install -r requirements.txt`
   - Start command: `uvicorn app.main:app --host 0.0.0.0 --port $PORT`
4. **Environment Variables**:
   | Переменная | Значение |
   |---|---|
   | `BOT_TOKEN` | токен из BotFather |
   | `DATABASE_URL` | строка из Neon |
      | `PYTHON_VERSION` | `3.12.8` |
   | `APP_TITLE` | `Арлан & Настя` |
5. **Create Web Service**. Через пару минут открой `https://<адрес>/health` — должно быть `{"ok":true}`.

На Render бот сам работает через webhook (Telegram будит сервер). Бесплатный сервис засыпает через 15 минут
без запросов — первое открытие после паузы грузится ~1 минуту, дальше быстро.

## 4. Привязать Mini App к боту

В @BotFather: `/mybots` → твой бот → **Bot Settings → Configure Mini App → Enable Mini App** → вставь `WEBAPP_URL`.
(Кнопка меню «💞 Мы» в чате с ботом выставляется автоматически при запуске.)

## 5. Связаться в пару

1. Ты пишешь боту `/start` → открываешь приложение → **«Создать нашу пару»** → **«Отправить приглашение»**.
2. Настя открывает ссылку → жмёт **Start** → вы связаны, тебе придёт уведомление.
3. На вкладке «Мы» укажи дату, с которой вы вместе.

> Важно: Настя должна хотя бы раз нажать **Start** у бота, иначе Telegram не даст боту присылать ей уведомления.

## Напоминания про настроение (9:00 и 21:00)

1. В Render → Environment добавь `CRON_SECRET` — любой длинный набор букв и цифр.
2. На **cron-job.org** создай 4 задачи (часовой пояс Asia/Almaty):
   | Время | URL |
   |---|---|
   | 08:58 | `https://<адрес>/health` — будит сервер |
   | 09:00 | `https://<адрес>/cron/mood?slot=morning&key=<CRON_SECRET>` |
   | 20:58 | `https://<адрес>/health` |
   | 21:00 | `https://<адрес>/cron/mood?slot=evening&key=<CRON_SECRET>` |

Повторный вызов в тот же день ничего не отправит.
Утренний вызов заодно поздравляет с круглыми датами (месяцы, годы, каждые 100 дней),
вечерний в воскресенье присылает итоги недели. Проверить итоги в любой день:
`/cron/mood?slot=evening&key=<CRON_SECRET>&weekly=1&force=1`.

## Чтобы приложение открывалось сразу

Render free засыпает через 15 минут без запросов, и первое открытие ждёт до минуты.
На cron-job.org добавь ещё одну задачу:

- URL: `https://<адрес>/health`
- Расписание: каждые 10 минут, с 08:00 до 23:59 (Asia/Almaty)

Бесплатных часов Render (750 в месяц) на это хватает: один сервис даже круглосуточно — около 744 часов.

## Локальный запуск (для разработки)

```bash
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env    # и заполни
uvicorn app.main:app --reload
```

Чтобы открыть интерфейс в обычном браузере без Telegram, в `.env` временно задай `DEV_USER_ID=1` и **не задавай** `BOT_TOKEN` — фото тогда сохраняются в `data/uploads`.
Второго человека для теста создай через запрос с другим `DEV_USER_ID` (перезапуск сервера).

⚠️ `DEV_USER_ID` **никогда не ставь на сервере** — с ним любой без Telegram войдёт под этим пользователем.
